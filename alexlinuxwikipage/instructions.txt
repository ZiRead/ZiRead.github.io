Установка ALT Linux
До входа в ОС:
1. Пароль от загрузчика: [пароль из базы знаний]
2. Обратить внимание на разметку разделов, выделить под корень весь диск.
3. Настройка сети в подсеть 192.168.111.X
4. Пароль сисадмина (root): [пароль из базы знаний]
5. Новая учетка: admn: пароль из базы знаний

После входа в ОС под admn:
1. Настройка сети опять (Если не сохранилась после установки)
2. Сменить hostname: В терминале (su root) - nano /etc/hostname
3. В терминале (su root): mc - иди по пути /etc/apt/source.list.d/
Через тот же mc редактируем файлы:
altsp.list - раскоментирувываем нижний блок репозиториев (http)
(этого может не быть) source.list - коментируем одну строку в нем
4.  В терминале (su root) apt-get update & apt-get install sudo nano yandex-browser-stable newt52 sane sane-airscan x11vnc-service
5. Установка VNC x11vnc (su root):
chkconfig x11vnc on
service x11vnc start
mkdir /etc/vnc
x11vnc --storepasswd
touch /var/log/x11vnc.log
nano /lib/systemd/system/x11vnc.service

[Unit]
Description=X11VNC Server
After=prefdm.service

[Service]
User=root
Restart=on-failure
ExecStart=/usr/bin/x11vnc -auth /var/run/lightdm/root/:0 -dontdisconnect -notruecolor -noxfixes -shared -forever -rfbport 5900 -oa /var/log/x11vnc.log -rfbauth /root/.vnc/passwd

[Install]
WantedBy=graphical.target

systemctl daemon-reload
systemctl start x11vnc.service
systemctl enable x11vnc.service
6. В терминале (su root) nano /etc/hosts - Добавить следующий текст:
192.168.100.1 Server-2015
192.168.100.2 Server-2016
192.168.100.100 Server-2017
192.168.100.249 Server-2024
7. (Альтернатива X11vnc-service это vino-mate. Предпочтительнее использовать x11vnc.) В верней панели: Система - Параметры - Интеренет и связь - Общий доступ к рабочему столу
 - Включаем доступ, отключаем запрос на подключение, указываем пароль: [пароль рабочего стола]. Для приминения требуется перезапуск сессии пользовтеля, для каждого пользователя включается отдельно.
8. Создание учетки: В верхней панели: Система - Центр управления - Центр управления системой (с паролем root) - Режим эксперта (сверху кнопка). Пользователи - Локальные учетные заПИСИ. Новая учетка запись - Пиши логин - Создать - Задай пароль и группы(если нужно) - Примернить (кнопка внизу), там же можно удалить(По необходимости).
9. Крипто-Хуипто: Копировать версию RPM (в обмене Солодкого) на комп и запустить скрипт install_gui.sh (собственно процесc идентичен аналогичному на Astra Linux). Расширение в браузер ставится из магазина вручную
10. Зайти на localhost:8080 под root - Группы - добавить в группу wheel - пользователя.
11. Установить R7: Взять пакет (в обмене Солодкого) - из терминала(su root): apt-get install ./<packege name> - Активировать файлом лицензии как обычно, тем же самым (да, он подходит к новой версии)
12. Установить 1С: Взять пакет (в обмене Солодкого) - из терминала(su root): apt-get install ./<packege name> - Добавить необходимые базы
13. Установить Bitrix24: Взять пакет (в обмене Солодкого) - из терминала(su root): apt-get install ./<packege name>
14. Настройка сканирования: Установить naps2: Взять пакет (в обмене Солодкого) - из терминала(su root): apt-get install ./<packege name>
15. Изменить настройку сети на подсеть 192.168.100.Х

После входа под юзверем:
1. Настройка печати: Зайди в CUPS(localhost:631) - Администрирование - Добавить принтер - Протокол интернет печати (ipp) - socket://<ip-adress> - Скорми ему PPD файл драйвера принтера - После завершения протестируй - Готово.

Если при удалении упирается в cprocsp-rdr-jacarta-64 -  sudo rm /var/lib/dpkg/info/cprocsp-rdr-jacarta-64.*

Отключение сохранения пароля от контейнера - sudo /opt/cprocsp/sbin/amd64/cpconfig -ini '\config\Parameters' -add long DisableSavedPasswords 1

Смена пароля на контейнер - opt/cprocsp/bin/amd64/csptestf -passwd -cont '<название_контейнера>' -change <новый_пароль> -passwd <старый_пароль>

Просмотр контейнеров - /opt/cprocsp/bin/amd64/csptest -keyset -enum_cont -fqcn -verifyc | iconv -f cp1251

Удаление контейнера - /opt/cprocsp/bin/amd64/csptestf -passwd -cont '<Название контейнера>' -deletek

Просмотр считывателей - /opt/cprocsp/sbin/amd64/cpconfig -hardware reader -view  или /opt/cprocsp/bin/amd64/csptest -enum -info -type PP_ENUMREADERS -flags 32

Установка сертификата в контейнер - /opt/cprocsp/bin/amd64/certmgr -inst -f <Путь к серту> -ask-container

Установить корневой сертификат - /opt/cprocsp/bin/amd64/certmgr -inst -store mRoot -file <ИМЯ СЕРТИФИКАТА>

Установить лицензию - sudo /opt/cprocsp/sbin/amd64/cpconfig –license –set <НОМЕР ЛИЦЕНЗИИ>

Просмотр статуса лицензии - sudo /opt/cprocsp/sbin/amd64/cpconfig -license -view

Просмотр физических хранилищ - /opt/cprocsp/sbin/amd64/cpconfig -hardware reader -view

Удаление из системы физических хранилищ - /opt/cprocsp/sbin/amd64/cpconfig -hardware reader -del FLASH
